# Hypotheses

One file per hypothesis, `H-YYMMDD-NN-<slug>.md` (header rules: `../PROTOCOL.md` §4). It has a statement, a rival,
the evidence so far and what would move it. `status`: `open`, `supported`, `weakened`, `refuted`, `proved`. A
hypothesis moves only through experiments that list it in `tests`, and every change names that experiment in
"Evidence so far". A failed search never accepts a hypothesis. The competing hypotheses that drive the queue are
listed in `../STATUS.md` §3a.
