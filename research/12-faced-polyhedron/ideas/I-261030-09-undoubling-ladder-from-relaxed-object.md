## Idea
From a relaxed object merge doubled collinear pairs one at a time (symmetry broken first), using normals first with exact offsets and the Gauss gate.

## Why it might help
A ladder that starts from an existing object.

## Cheapest test
Needs L1 first; calibrate on RV's 8-face polyhedron, measure how far merging gets.

## Why parked (2026-11-01)

Undoubling a pair removes an edge and changes the genus; it is a surgery, not a path in a realization space, so an S1
object gives no continuation towards S0. S1 objects remain goals in themselves (E-261101-08).
