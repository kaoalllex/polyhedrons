# Ideas

One file per idea, `I-YYMMDD-NN-<slug>.md` (header rules: `../PROTOCOL.md` §4). An idea is a proposed method,
construction, test or analogy. It becomes a hypothesis (`../hypotheses/`) or an experiment (`../experiments/`),
which then lists it in its `origin`. `status`: `open` (not tried), `tried` (some experiment ran it), `parked` (set
aside, with the reason in the file). The map (`../map/index.html`) shows what grew out of each idea.

The ideas written before 2026-11-01 were split out of older notes on that day: `cross-field-ideas.md`,
`search-algorithms.md`, `brainstorm-2026-10-30-analysis.md`, `literature/scout-leads.md`, `archive/*.md`, the
2026-10-30 review, the fresh-eyes review and the 2026-10-31 internal audit. Their "Source" lines name those
documents; the originals are in git tag `state-2026-11-01`.

To add an idea, take the next free number for today and write the file. One line of idea is enough; the cheapest
test and the source make it useful.
